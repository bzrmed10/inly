# Inly

Aligner wear timer for iPhone, built around the Dynamic Island, Live Activities, widgets and iOS 26 Liquid Glass.

- Swift 6, SwiftUI, SwiftData, ActivityKit, WidgetKit, App Intents
- Minimum iOS: 26
- Bundle ID: `com.bzrmed.inly` (widgets: `com.bzrmed.inly.widgets`, App Group: `group.com.bzrmed.inly`)

See `SPEC.md` for the product spec, `ROADMAP.md` for the task list and `REPORT.md` for progress.
